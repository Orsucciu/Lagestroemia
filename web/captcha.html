Manual fallback

If the captcha above doesn't work (e.g. it solves but the app still says "captcha required"), solve it on chat.z.ai instead and paste the result here.

  1. Open chat.z.ai in a new tab.
  2. Sign in there (it auto-creates a free guest account).
  3. Type any message and send it — the captcha will appear.
  4. Solve the captcha on chat.z.ai.
  5. Open DevTools (F12) → Network tab.
  6. Find the POST /api/v2/chat/completions request.
  7. Click it → Payload tab → copy the value of the captcha_verify_param field (a long base64 string starting with eyJ).
  8. Paste it below and click "Send to app".
